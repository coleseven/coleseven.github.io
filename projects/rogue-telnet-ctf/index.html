Overview

Rogue Telnet CTF is a simple Telnet server running on an unusual port. The goal of the event was for students to use an nmap scan to find the port the server was running on, connect to it, and then explore what they could see and do.

Problem / Goal

The goal was to create a simple, approachable introductory CTF for an Ethical Hacking undergraduate class at USCB. I aimed to make it doable by anyone in the class, as long as they explored everything they were given access to.

Approach

I implemented a custom Telnet server that allowed unauthenticated access while enforcing a strict whitelist of commands. Flags were hidden across the filesystem and environment, rewarding careful exploration rather than brute force.

Results / Outcome

This event went very well — I believe every student but one found every flag. There was one big issue, though, and I'm still not completely sure of the cause. Students were interacting with the Telnet server from Raspberry Pis, and when the Pis ran nmap scans they didn't always resolve, so some students struggled to find the open port. I believe setting up a dedicated DNS would fix this.

What I Learned

I learned that no matter how much you test or prepare, something will always go wrong. That isn't a bad thing — it's just something you have to plan for when building and running a CTF event.
